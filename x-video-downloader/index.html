X Video Downloader

Download a video from a public X post in your browser. Paste an x.com post link to see the real formats the source provides, then save the file to your phone or computer. X is the platform formerly known as Twitter.

How do I download a video from X? Copy a link to a public X post that contains a video, paste it into the box above, and press Download. Review the real formats returned for that post, choose one, then press Download again to save the file. Private and restricted posts are not supported.

How to download a video from X

  1. Copy the X post link. Open the post on x.com, tap or click the share icon, and choose Copy link. The address must point to one post and contain /status/ followed by the post number.
  2. Paste the link and analyze. Put the address in the box above and press Download. The server reads the public post and returns its real title, duration, and available formats.
  3. Pick a format. Each result shows the actual container, resolution, and file size. A + audio label means a compatible audio track will be merged with the selected video stream.
  4. Save the file. Press Download again to prepare the file. Your browser saves it to the usual downloads location using the post title as the filename.

Copy an X post link from the app or browser

On the X mobile app

Open the post, tap the share icon, and choose Copy link. If an in-app browser does not show the share menu, copy the address from the browser bar instead. A valid link looks like x.com/username/status/ followed by the post number.

On a desktop browser

On x.com, use the share icon on the post and choose Copy link, or select the address bar directly. An older twitter.com URL also works because it reaches the same public post.

Which X links work

This downloader for X videos accepts individual posts from x.com and twitter.com, including addresses with www, m, or mobile. The x.com video downloader reads public posts only. The URL must contain /status/ and the post number. Profiles, searches, hashtags, lists, communities, and photo-only or text-only posts cannot be processed. No login is used, so protected and restricted content is out of scope.

What the results show

The results panel uses the metadata returned for that post: title, thumbnail, duration, and the formats the source exposes. Quality labels reflect the real streams, so a lower-resolution post is not displayed as a higher one. When separate video and audio tracks exist, the options are labeled accordingly, audio-only formats may appear, and an option marked + audio will be merged. The container shown in the results is the container you receive. For a format-specific walkthrough, see the Twitter MP4 downloader.

X downloads on iPhone, Android and desktop

iPhone and iPad

The tool runs in Safari or another browser, so no app is required. Files usually go to Files, then Downloads. If iOS shows a share sheet, choose Save to Files and pick a folder you can find later.

Android

Chrome and other browsers save the file to the Downloads folder. Open it from Files or from the browser's download list. Most Android galleries and players open the saved file without extra software.

Windows and Mac

The file goes to your browser's default downloads folder. Press Ctrl+J on Windows or ⌘+Shift+J on macOS to open the downloads list and confirm the filename and location.

Why an X video download can fail

  • The post is protected or login-only. Private accounts, follower-only posts, and members-only content are refused. Access controls are never bypassed.
  • The post was deleted or the account was suspended. The video no longer exists for the server to read.
  • The post has no video. Text, photo, and link-only posts have nothing to save. Photos are outside this tool's scope.
  • The content is age-restricted or unavailable in your region. Restricted posts need a login that this tool does not use.
  • The address is not a single post. Copy a link that contains /status/ and the post number, not a profile, search, hashtag, list, or community page.
  • The request was rate-limited or the upstream service refused it. Wait a minute and try again instead of sending repeated requests.

Privacy and data handling

The post link is sent to the StartDownloading server only to read the public post and prepare the selected file. You do not create an account, log in to X, or provide cookies. Prepared files are written to temporary storage and removed automatically about ten minutes after they are created. Server logs keep the hostname and outcome of a request rather than the full pasted URL, so the complete link is not written to disk as a record. No persistent copy is stored in your browser beyond the page itself.

Frequently asked questions

Is this X video downloader safe to use?

It never asks for your X password, cookies, or login. The post link is sent to the StartDownloading server only to read the public post, prepared files are temporary and removed automatically, and access controls are never bypassed. Save only content you have permission to download.

Is the downloader free?

Yes. There is no account, subscription, or payment required. Normal rate limits apply so the service stays available, and you can use it as often as those limits allow.

Does it support x.com links?

Yes. Individual post links from x.com and legacy twitter.com URLs are accepted, including www and mobile variants. The address must contain /status/ followed by the post number; profile, search, hashtag, list, and community links are not supported.

Why did my X link fail?

The most common reasons are a private or deleted post, an age or region restriction, a post with no video, a profile or search link instead of a single post, a rate limit, or a temporary upstream refusal. Check the address and try again later.

Can I download a video from a protected X account?

No. The downloader works only with public posts. Protected accounts, follower-only posts, login-only pages, and age-restricted content are refused, and access controls are never bypassed.

Does it work on iPhone and Android?

Yes. It runs in the browser without an app. On iPhone and iPad the file normally goes to Files, then Downloads; if a share sheet appears, choose Save to Files. On Android, Chrome saves it to the Downloads folder.

What formats and quality can I choose?

You see the formats and resolutions the source actually provides, and each option shows its real container. Nothing is invented or upscaled.
